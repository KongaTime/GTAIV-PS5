# Historical development scripts

These scripts preserve the original integration, diagnostics and packaging
work for reference. Local usernames, workstation paths and console
addresses have been replaced by `/home/developer`, `/path/to/workspace`
and `PS5_IP` placeholders. They reference historical intermediate build
trees and are **not supported commands to run unchanged**. Some describe
earlier fixes or abandoned diagnostic variants.

The final code is in `prospero-win/`; the final additional server source
is in `wineserver-changes/`. Use root `docs/BUILD.md`, `scripts/` and
`tests/` for the public workflow. Keep production game folders and saves
out of development experiments.
